# 豆包环境 · 一键宝塔 + 自助建站

在 **豆包工作区**（以及任何 rootfs 易重置、无 systemd、无公网 IP 的容器）里，一条命令部署出：

- ✅ **宝塔面板**（含容器兼容补丁，安装不再卡死）
- ✅ **MySQL 8 快速安装**（离线预编译包**秒装**；无离线包时自动在线下载官方预编译二进制，3–8 分钟，替代 1–2 小时的源码编译）
- ✅ **PHP 8.1 一键安装**（`bt_res/` 离线预编译包**秒装**；无预编译包时自动用包内官方源码并行编译，20–40 分钟；装好即被面板识别）
- ✅ **公网访问**（cloudflared / serveo 内网穿透，零配置、免备案、免公网 IP）
- ✅ **多端口自助建站**（20001–20030 共 30 个端口，面板里添加站点即自动暴露公网地址）
- ✅ **站点导航页**（自动生成"我的服务器站点导航"，所有站点公网地址一目了然）
- ✅ **沙箱重置自恢复**（数据落盘持久目录，重置后一条命令满血复活）
- ✅ **自动汇报**（部署/恢复完成后自动生成汇报单，含面板账号密码、数据库密码、所有网址）

> 本项目是环境/平台层的部署方案，不含任何个人的站点源码与数据、不含任何账号密码与服务器地址。敏感信息全部参数化/占位，请放心分发。

## ⭐ 傻瓜三步走（不会用终端也够用）

> 详细大白话指令见 **`docs/05-傻瓜操作手册.md`**，下面每句话都能直接发给豆包。

**第 1 步 · 首次部署**：把整个项目发给豆包，然后对它说：

> 帮我把这个服务器环境一键装好：运行 `bash one-click.sh`，装完读 `/tmp/bt_summary.txt`，用大白话告诉我控制台网址、登录账号密码、数据库密码，以及我接下来怎么建第一个网站。

**第 2 步 · 被重置后修复**：对豆包说：

> 服务器刚才被重置了，运行 `bash restore.sh` 帮我恢复，恢复完读 `/tmp/bt_summary.txt`，用大白话告诉我网站和数据库还在不在、控制台地址密码有没有变、手机能不能打开。

**第 3 步 · 日常建站**：对豆包说：

> 帮我看下哪些端口空闲，教我在面板里怎么添加新网站（点哪里、域名填什么格式），说人话。

豆包会替你把命令跑完，然后**用大白话汇报结果并教你下一步**，你不需要去翻文档。

## 一、一键部署

在豆包工作区（或任何 Linux 容器）里执行：

```bash
# 1. 拿到项目（GitHub 克隆 / 上传解压 / 直接发给豆包解析均可）
git clone <本仓库地址> && cd doubao-bt-deploy

# 2. 跑总入口（全程自动，日志 /tmp/bt_oneclick.log）
bash one-click.sh
```

> **离线资源（可选加速，强烈建议）**：把 GitHub Release 里的 `mysql-8.0.40-linux-glibc2.17-x86_64.tar.xz`、`php81-prebuilt.tar.xz` 放进项目的 `bt_res/` 目录，部署时 **MySQL 和 PHP 都是秒装**（解压即用，不再下载/编译）。Release 地址见本仓库页面右侧 Releases。不放也行：MySQL 会自动在线下载（3–8 分钟），PHP 自动用包内源码编译（20–40 分钟）。

完成后查看 `/tmp/bt_oneclick.log` 末尾的汇总：

| 项目 | 位置 |
| --- | --- |
| 宝塔面板 | `https://127.0.0.1:<面板端口>`（登录信息见面板首页/`/www/server/panel/default.pl`） |
| 面板公网地址 | `grep -E 'trycloudflare' /tmp/tunnel_panel.log` |
| 站点导航页 | 默认站点 `http://127.0.0.1:8088`（公网地址见 `/tmp/tunnel_web.log`） |

### 分步执行（不想要全自动时）

```bash
bash scripts/persist-www.sh      # 1. /www 持久化（防重置丢数据）
bash scripts/install-bt.sh       # 2. 宝塔面板（容器补丁）
bash scripts/mysql-quick.sh      # 3. MySQL 8 快装（几分钟）
PORT=8888  bash scripts/tunnel.sh panel https   # 4a. 面板公网隧道
PORT=8088  bash scripts/tunnel.sh web http     # 4b. 默认站点公网隧道
sudo nohup bash scripts/sites-monitor.sh &     # 5. 多端口建站监控 + 导航页
bash scripts/summary.sh          # 6. 汇总汇报单（账号/密码/地址）
```

### 发给豆包/助手执行：完成后必须汇报

部署完成后，**豆包/助手应把汇报单 `/tmp/bt_summary.txt` 完整读给用户**（one-click.sh 已自动生成并打印），汇报单包含：

| 汇报项 | 内容 |
| --- | --- |
| 宝塔面板 | 本地地址 + 公网地址 + **登录账号/密码**（登录后立即改密） |
| MySQL 8 | root **密码**（请用户抄录，勿外传） |
| 站点导航页 | 本地地址 + 公网地址 |
| 使用方法 | 建站步骤、重置恢复命令 |
| 安全提醒 | 临时密码/隧道地址变动提示 |

可直接复制给豆包/助手执行的提示词：

> 请运行 `bash one-click.sh` 完成一键部署。部署完成后，读取
> `/tmp/bt_summary.txt`，把面板登录账号密码、MySQL root 密码、
> 面板公网地址、站点导航页地址逐项汇报给我，并提醒我立即修改默认密码。

## 二、沙箱重置后恢复

豆包工作区重置（rootfs 还原）后，宝塔数据在持久目录里原封不动：

```bash
bash scripts/restore.sh
```

自动完成：重建 `/www` 软链接 → 启动面板/nginx/php/mysql → 重起公网隧道 → 恢复站点监控与导航页。

> 前提：部署时用过 `persist-www.sh`（one-click.sh 已内置），持久目录里有 `bt_data/www`。

    ├── 02-弯路与避坑.md        # 踩过的坑：编译、端口、重置、隧道
    ├── 03-多站点自助建站.md    # 端口段方案与导航页使用
    ├── 05-傻瓜操作手册.md      # ⭐ 给豆包/助手的大白话指令（复制即用）
    └── 06-宝塔添加站点小白教程.md # ⭐ 域名一栏怎么填（超详细大白话，含错误示范）

## 四、环境要求

- Linux x86_64（Debian/Ubuntu 系最佳）
- 有 `sudo` 权限
- 能访问外网（下载宝塔安装脚本与隧道二进制）
- 无需公网 IP、无需域名备案

## 五、安全说明

- MySQL root 密码由脚本随机生成并打印在日志，**请复制到自己的密码本**
- 宝塔面板登录信息见面板首页输出，**首次登录请立即改密**
- trycloudflare 临时隧道地址每次重启会变化，正式使用可换 named tunnel（见 `docs/02-弯路与避坑.md`）
- 本项目不包含任何真实账号、密码、IP、域名或站点数据
