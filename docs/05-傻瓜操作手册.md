# 05 · 傻瓜操作手册（给豆包/助手的大白话指令）

不会用终端？看不懂文档？没关系——下面每段话**直接复制发给豆包**，
豆包会帮你跑命令、查结果，然后用大白话告诉你该做什么、账号密码是什么。

---

## 一、第一次部署（从零装好环境）

直接复制这句发给豆包：

> 帮我把这个服务器环境一键装好：运行 `bash one-click.sh`。
> 装完以后，读一下 `/tmp/bt_summary.txt`，然后用**大白话**告诉我：
> 1. 控制台（面板）网址——本地的和手机能打开的各一个；
> 2. 控制台的账号和密码；
> 3. 数据库（MySQL）的密码；
> 4. 接下来我想建第一个网站，我该怎么做——不要贴命令，直接说在哪个页面点哪里、填什么。
>
> 汇报时别说术语，就说人话。比如：
> "你的控制台在 https://xxx，账号 admin，密码 xxx，进去第一件事改密码；
> 建网站就点左侧『网站』→『添加站点』，域名一栏填 你的名字:20001 这样的格式。"

豆包会做的事：跑安装 → 生成汇报单 → 按上面格式用大白话汇报。

## 二、沙箱/服务器重置之后（一键修复）

只要服务器被重置（环境丢了），复制这句发给豆包：

> 服务器刚才被重置了，你帮我把环境恢复回来：运行 `bash restore.sh`。
> 恢复完读一下 `/tmp/bt_summary.txt`，用**大白话**告诉我：
> 1. 我之前建的网站和数据库还在不在（数据应该都还在，确认一下）；
> 2. 控制台网址、账号密码有没有变；
> 3. 手机能不能打开了（给我手机能开的网址）。
>
> 还是那句：说人话，别贴一堆命令。

豆包会做的事：重建软链 → 重启面板/网站/数据库 → 重新开公网地址 → 汇报。

> 如果连项目文件都没了（重置得很彻底），先把项目重新弄进来，再跑上面这句。

## 三、日常操作（不用记命令）

| 你想做什么 | 直接发给豆包这句话 |
| --- | --- |
| 建新网站 | 帮我看一下现在哪些端口空闲，然后教我在面板里怎么添加一个新网站（点哪里、域名填什么格式），说人话。 |
| 看所有网站的地址 | 帮我看一下现在一共有几个网站，把每个网站的公网地址用大白话列给我。 |
| 手机上打开控制台 | 我的控制台手机打不开了，帮我重新弄一个手机能打开的控制台地址。 |
| 网站打不开了 | 我的网站打不开了，帮我检查一下是不是隧道掉了，重新起一下公网地址。 |
| 看数据库 | 帮我连一下数据库，看看里面有哪些库和表，告诉我（别把密码公开贴出来）。 |
| 忘记面板密码 | 我的控制台密码忘了，帮我看看默认密码文件里是什么，或者教我怎么重置。 |

豆包会自己跑对应脚本（`sites-monitor.sh` / `tunnel.sh` / `summary.sh` 等），
然后只用大白话回答你。

## 四、豆包汇报的"大白话"标准

要求豆包汇报时遵循：

- 不要说"请运行 bash xxx.sh"，直接告诉用户**结果**和**下一步动作**
- 账号密码等敏感信息单独说，提醒用户"记下来，别告诉别人"
- 术语翻译：面板=控制台/后台、隧道=让手机能访问的通道、导航页=所有网站地址的汇总页
- 每条信息都告诉用户"这有什么用、什么时候会用到"

## 五、你只需要记住的 3 句话

1. **第一次用**：把项目发给豆包 + 说"帮我部署"（上面的模板一）
2. **被重置了**：说"帮我恢复"（上面的模板二）
3. **想建网站**：说"帮我看哪些端口空闲 + 教我怎么加站点"（模板三）

剩下的全部交给豆包，它会跑脚本 + 用大白话汇报。

## 六、离线资源（想更快就放这个）

部署时 MySQL 和 PHP 需要"安装包"。想**秒装**的话：

1. 打开 GitHub 仓库页面 → 右边 **Releases** → 下载：
   - `mysql-8.0.40-linux-glibc2.17-x86_64.tar.xz`（MySQL，约 820MB）
   - `php81-prebuilt.tar.xz`（PHP，约 70MB，官方源码编译的标准产物）
2. 放进项目的 `bt_res/` 文件夹（没有就新建一个）
3. 再部署：MySQL 和 PHP 都是**解压即用，1 分钟搞定**

不放也行：MySQL 自动在线下载（3–8 分钟），PHP 自动用包里的官方源码编译（20–40 分钟）。
这些包都是**官方原包/官方源码编译产物，不含任何个人信息**。
