# 07 · 部署完成后的一键建站指引（给豆包/助手的剧本）

> 场景：`one-click.sh` 部署完成后，豆包读完汇报单，**主动向用户提问是否一键建站**。
> 用户选择模板后，豆包按本文件对应章节，用已部署好的宝塔环境帮用户把站建出来。
> 全程大白话，不要让用户动手操作。

---

## 一、部署完成后，豆包先做这件事（提问）

读完汇报单、把账号密码和网址告诉用户之后，紧接着问：

> “要不要现在帮你**一键建个网站**？有这几种，你选一个（回数字就行）：
>
> **1️⃣ 个人主页** —— 最简单，1 分钟搞定，个人名片/自我介绍（不用数据库）
> **2️⃣ WordPress 博客** —— 最流行的博客，可写文章、换主题
> **3️⃣ Typecho 博客** —— 轻量博客，速度快、界面简洁
> **4️⃣ ZBlog 博客** —— 国产博客程序，中文支持好、插件多
>
> 不想建也没关系，说“不用”就行，以后想建随时叫我。”

- 用户说"不用" → 结束，不再打扰。
- 用户选了一个 → 按下面对应章节执行。

---

## 二、建站前通用准备（每种站都要做）

1. **打开面板**：用汇报单里的面板网址 + 账号密码登录（用户不用管，豆包代操作或引导）。
2. **确定端口**：读导航页/`ports.txt`，找下一个没占用的端口（第一个站用 20001，第二个 20002……按顺序）。
3. **添加站点**：面板 → 网站 → 添加站点 → 「域名」填 `你的名字.后缀:端口`（如 `test.com:20001`，名字随便编、后缀随便选，**端口一定要用上面确定的那个**）→ 提交。
   - PHP 版本：如果装了 PHP 8.1 就选 8.1；没有就选默认。
   - 数据库：WordPress/Typecho/ZBlog 选"创建数据库"（记下数据库名、用户名、密码，豆包代填）。
4. **上传/放置程序文件**：把程序解压到站点根目录 `/www/wwwroot/<域名>/`（宝塔默认站点根）。
5. **安装向导**：浏览器打开 `https://<站点公网地址>` 走安装向导，按提示填数据库信息（豆包代填，从第 3 步记的信息里抄）。
6. **完成**：装好后告诉用户"你的网站好了：`https://xxx.trycloudflare.com`"。

> 站点公网地址从**导航页**看：建站约 30 秒后刷新导航页，站点列表里那一行就是公网地址。

---

## 三、各站点一键建站详细步骤

### 1️⃣ 个人主页（最简，推荐第一个站用它）

纯静态 HTML，**不需要数据库、不需要 PHP**，最稳。

1. 面板 → 网站 → 添加站点（域名填 `名字.后缀:端口`，如 `wodezhan.top:20001`，PHP 选"纯静态"）
2. 把项目 `templates/personal-page/index.html` 上传/复制到站点根目录（替换默认 index 页）
3. 可选：帮用户把模板里的占位内容（名字、介绍、技能、项目、联系方式）改成用户自己的
4. 刷新导航页拿公网地址，告诉用户

### 2️⃣ WordPress 博客（最流行）

1. 添加站点（含创建数据库，记下库名/用户/密码）
2. 下载官方程序（豆包执行）：
   ```bash
   cd /tmp && wget -O wp.zip https://cn.wordpress.org/latest-zh_CN.zip && unzip -q wp.zip -d /tmp/wp_src
   ```
   （国内用户用 `cn.wordpress.org` 更快；下不了换 `wordpress.org/latest.zip`）
3. 把解压出来的 `wordpress` 目录里的**所有文件**放到站点根目录（`cp -a /tmp/wp_src/wordpress/. /www/wwwroot/<域名>/`）
4. 给站点根目录写权限：`chown -R www:www /www/wwwroot/<域名>`
5. 浏览器打开站点公网地址 → 按向导安装：
   - 数据库名/用户名/密码用第 1 步创建的
   - 站点标题、管理员账号密码帮用户设置（并告诉用户记住）
6. 装完打开首页确认，告诉用户后台地址是 `https://公网地址/wp-admin`

### 3️⃣ Typecho 博客（轻量）

1. 添加站点（创建数据库，记下信息）
2. 下载官方程序：
   ```bash
   cd /tmp && wget -O typecho.zip https://github.com/typecho/typecho/releases/latest/download/typecho.zip && unzip -q typecho.zip -d /tmp/typecho_src
   ```
   （GitHub 慢就用项目里的下载器：`bash scripts/fetch.sh <上面那个URL> /tmp/typecho.zip` 再解压）
3. 把解压后的文件放到站点根目录（注意如果多套了一层目录，取其内容）
4. `chown -R www:www /www/wwwroot/<域名>`
5. 打开公网地址走安装向导：填数据库信息 + 管理员账号
6. 完成后告诉用户地址和后台地址（`/admin`）

### 4️⃣ ZBlog 博客（国产）

1. 添加站点（创建数据库）
2. 下载官方程序：
   ```bash
   cd /tmp && wget -O zblog.zip https://www.zblogcn.com/zb_users/theme/download/... 
   ```
   （或让豆包搜“ZBlog 官网”找最新安装包下载链接，解压到站点根目录）
3. `chown -R www:www /www/wwwroot/<域名>`
4. 打开公网地址走安装向导（ZBlog 安装页会自动检测环境，填数据库信息即可）
5. 完成后告诉用户地址与后台地址（`/zb_system/login.php`）

---

## 四、建完必做的事（汇报要求）

建好后**必须**用大白话汇报：

1. 网站地址（`https://xxx.trycloudflare.com`，让它**在浏览器里打开确认页面正常**）
2. 后台地址 + 管理员账号密码（提醒用户记下来、改掉默认密码）
3. 数据库名/用户名/密码（提醒用户存好）
4. 一句"以后想换模板/加页面，随时叫我"

---

## 五、注意事项

- 所有账号密码**只告诉当前用户**，不要写进任何文件/日志
- 模板 `templates/personal-page/` 是通用占位内容，**不含任何人的真实信息**，可放心给用户改
- 站点内容与一键部署项目无关，属于用户自己的网站，**不会上传到 GitHub**
