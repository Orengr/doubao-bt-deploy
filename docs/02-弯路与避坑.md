# 02 · 弯路与避坑（实测记录）

以下全部是真实踩过的坑，按"现象 → 原因 → 解法"记录。

---

## 1. MySQL 源码编译装了整整半天（最大弯路）

**现象**：宝塔软件商店装 MySQL，源码编译 1–2 小时起，中途还可能因内存不足被 kill。

**原因**：宝塔默认源码编译；容器内存小，编译 mysql 极慢。

**解法**：
- 用官方**预编译二进制**（`mysql-*-linux-glibc2.17-x86_64.tar.xz`），解压即用，3–8 分钟。见 `scripts/mysql-quick.sh`。
- **更快的思路**：预编译二进制本质就是"别人装好的 MySQL 的目录拷贝"。所以把任意一台同架构机器上装好的 `/www/server/mysql` 整个 `cp -a` 过来，`chown mysql:mysql`、初始化数据目录、`/etc/init.d/mysqld start` 就能直接用。
- 下载源顺序：官方 CDN → 清华镜像 → 阿里镜像。

## 2. 宝塔安装脚本在容器里卡死（两处死循环）

**现象**：`install_panel.sh` 装到一半长时间无输出。

**原因**（两处）：
1. `Fix_Apt_Lock()`：函数内部扫描 `/proc/*/cmdline`，容器 /proc 特殊，全量扫描死循环。
2. `Apt_Ready()`：对 apt-get 做探测更新，容器内无意义且可能卡住。

**解法**：装前打补丁（`install-bt.sh` 已内置）：

```bash
sed -i 's#\[ ! -f "/usr/bin/apt-get" \] && return 0#return 0  # container patch#' install_panel.sh
sed -i '/^Apt_Ready(){$/{n;s/.*/    return 0  # container patch/;}' install_panel.sh
```

## 3. sudo 丢环境变量导致强制安装不生效

**现象**：`INSTALL_FORCE=true sudo bash install_panel.sh` 仍然进入交互确认。

**原因**：sudo 默认 `env_reset`，外部 export 的变量进不了 sudo 内部。

**解法**：把 export 写进 sudo 的 bash -c 里：

```bash
sudo bash -c 'export INSTALL_FORCE=true && cd /tmp && bash install_panel.sh -y ed8484bec'
```

## 4. 沙箱重置后一切消失（rootfs 还原）

**现象**：工作区重置，宝塔、站点、数据库全部回到初始。

**原因**：宝塔数据在 rootfs 的 `/www`，重置即清空。

**解法**：
1. 部署**前**就把 `/www` 软链到持久目录（`persist-www.sh`）。
2. 重置后跑 `restore.sh`：重建软链 → 启动面板/nginx/php/mysql → 起隧道 → 恢复站点监控。

## 5. 无公网 IP，网站外面访问不了

**现象**：面板、站点本地都能开，手机打不开。

**原因**：容器是 NAT 出口，没有公网 IP，端口不可达。

**解法**：内网穿透。
- cloudflared quick tunnel（trycloudflare）：免账号，`cloudflared tunnel --url http://127.0.0.1:<端口>`。
- 备用：serveo（`ssh -R 443:127.0.0.1:<端口> serveo.net`）。
- 要固定域名：Cloudflare named tunnel（需有域名，但无需备案）。

## 6. 面板 HTTPS 自签证书打不开/被拦截

**现象**：`https://127.0.0.1:<端口>` 报证书错误。

**原因**：宝塔自签证书。

**解法**：临时隧道给面板套 `https`（cloudflared `--url https://127.0.0.1:<端口> --no-tls-verify`），手机直接访问隧道 https 地址即可。

## 7. 多端口建站的端口选择

**现象**：所有站点挤在一个端口（80/8088），互相冲突。

**解法**：约定端口段 `20001–20030`（30 个），一个站点一个端口：
- 面板添加站点，域名写 `名字.后缀:端口`（如 `test.com:20001`）。
- 端口到公网地址的映射由 `sites-monitor.sh` 自动维护，导航页自动展示。
- 端口段用完后可扩展（改 `ports.txt`）。

## 8. cloudflared 下载慢 / 二进制缺失

**现象**：隧道起不来，日志空。

**解法**：
- 官方地址：`https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64`
- 下载后 `chmod +x`，放工作区复用（沙箱重置后记得重新下载或提前放持久目录）。
- 面板隧道日志 `/tmp/tunnel_panel.log`，网站隧道日志 `/tmp/tunnel_web.log`。

## 9. PHP 编译也慢（可选优化）

**现象**：面板装 PHP 8.1 也走编译，几十分钟。

**解法**：
- 不着急的话等它编译完（面板全自动）。
- 着急：面板 → 软件商店 → PHP → 已有二进制安装源（若有），或先跳过 PHP 只跑静态站 + MySQL。
- 容器内 PHP-FPM 启动：`/etc/init.d/php-fpm-81 start`（没有 systemd）。

## 10. 常驻进程被沙箱回收

**现象**：过一段时间监控/隧道进程没了。

**原因**：沙箱可能回收长驻进程。

**解法**：
- 监控脚本用 `nohup ... &` 且日志重定向（已在脚本内）。
- 重置/重启后统一跑 `restore.sh` 一次，全部进程会拉起。
