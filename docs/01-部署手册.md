# 01 · 部署手册（从零开始）

本文记录在豆包工作区（无 systemd、无公网 IP、rootfs 易重置的容器）里，
从空环境到「宝塔面板 + 多端口自助建站 + 公网访问」的完整路径。

---

## 0. 环境认知（先看这个，避免白忙）

| 特性 | 豆包工作区 | 影响 |
| --- | --- | --- |
| 无 systemd | 只有 `init.d` 脚本 | 宝塔/nginx/mysql 全部用 `/etc/init.d/* start` 启停 |
| 无公网 IP | 出口是 NAT | 公网访问必须走内网穿透（隧道） |
| rootfs 易重置 | 重置后 /www 消失 | 必须把数据放持久目录（`persist-www.sh`） |
| /proc 特殊 | 全量扫描会卡死 | 宝塔安装脚本需打补丁（`install-bt.sh` 已处理） |
| sudo 丢环境变量 | env_reset | 传给 sudo 的环境变量要在 sudo 内部重新 export |

---

## 1. 持久化 /www

宝塔硬编码 `/www` 路径。沙箱重置会清掉 rootfs，所以一开始就把 `/www` 指向工作区持久目录：

```bash
bash scripts/persist-www.sh
# 效果: /www -> <工作区>/bt_data/www （软链接）
```

之后宝塔、nginx、站点文件全在持久目录里，重置不丢。

## 2. 安装宝塔面板

```bash
bash scripts/install-bt.sh
```

脚本做的事：
1. 下载官方安装脚本 `https://download.bt.cn/install/install_panel.sh`
2. **打两个容器补丁**（关键，否则安装会卡死）：
   - `Fix_Apt_Lock()`：容器内扫描 `/proc` 死循环 → 直接 `return 0`
   - `Apt_Ready()`：容器内 `apt-get update` 无意义 → 直接 `return 0`
3. `INSTALL_FORCE=true` 强制安装，跳过交互
4. 轮询面板端口就绪

安装完看 `/tmp/bt_install.log`：
- 面板端口（`SERVER_IP:端口`）
- 登录地址 `https://127.0.0.1:<端口>`
- 账号密码：面板首页输出 / `/www/server/panel/default.pl`

> 面板默认会装 nginx 并**编译安装 PHP**（几十分钟）。着急的话可以先跳过 PHP
> （面板软件商店里选已有二进制/后续再装），MySQL 直接用下面的快装法，不依赖面板。

## 3. MySQL 8 快速安装（重点：避开编译坑）

**千万不要源码编译**（1–2 小时）。用官方预编译二进制，3–8 分钟：

```bash
bash scripts/mysql-quick.sh          # 默认 8.0.40
bash scripts/mysql-quick.sh 8.4.3    # 指定版本
```

原理与要点：
- 下载 `mysql-<版本>-linux-glibc2.17-x86_64.tar.xz`（约 800MB，官方 CDN 失败自动换清华镜像）
- 解压即用：`cp -a ... /www/server/mysql/`
- 缺依赖装：`libaio1 libncurses5 libnuma1`（容器常缺）
- `mysqld --initialize-insecure` 初始化数据目录
- `support-files/mysql.server` 拷为 `/etc/init.d/mysqld`（容器无 systemd 就用它）
- root 密码随机生成，打印在 `/tmp/mysql_quick.log` 顶部，**务必复制保存**

> 想更快：把别人装好的 `/www/server/mysql` 整个目录拷过来（同 x86_64 + 同 glibc 环境）
> 直接就能用——预编译二进制就是干这个的，本脚本只是把"拷贝"自动化了。

## 4. 公网访问（内网穿透）

无公网 IP 时用 cloudflared 零配置隧道：

```bash
PORT=8888  bash scripts/tunnel.sh panel https   # 面板隧道
PORT=8088  bash scripts/tunnel.sh web http      # 默认站点隧道
```

- 输出：`grep -E 'trycloudflare' /tmp/tunnel_panel.log`
- 特点：免账号、免备案、免域名，30 秒出地址
- 缺点：临时隧道地址重启会变；要固定地址用 Cloudflare named tunnel（见避坑文档）

备用隧道（cloudflared 下载失败时）：`ssh -R 443:127.0.0.1:<端口> serveo.net`（serveo 免费 SSH 隧道）。

## 5. 多端口自助建站 + 导航页

```bash
sudo nohup bash scripts/sites-monitor.sh &
```

常驻监控做的事：
1. 每 20 秒扫描宝塔 nginx 站点配置
2. 发现新端口站点 → 自动起一条 cloudflared 隧道 → 公网地址写入 `sites.txt`
3. 自动生成 **站点导航页**（默认站点根目录 `index.html`）
4. 站点被删除 → 自动关隧道、清记录、刷新导航页

建站方式（面板里操作）：
> 面板 → 网站 → 添加站点 → 域名填 `名字.后缀:端口`（如 `test.com:20001`）→ 确定

约 30 秒后打开导航页，就能看到新站的公网地址。

## 6. 常用运维命令

```bash
# 面板
sudo /etc/init.d/bt start|stop|restart
# nginx
sudo /etc/init.d/nginx start|stop|reload
# PHP（面板装的 8.1）
sudo /etc/init.d/php-fpm-81 start|restart
# MySQL
sudo /etc/init.d/mysqld start|restart
# 隧道
pkill -f cloudflared    # 全部停
bash scripts/tunnel.sh web http   # 重起
```

- [ ] 面板公网地址在手机能打开
- [ ] 导航页显示面板地址 + 站点列表
- [ ] MySQL：`/www/server/mysql/bin/mysql -uroot -p'<root密码>' -e 'SELECT 1'`
