# 03 · 多站点自助建站指南（端口段方案）

核心思路：**一个容器跑多个网站**，每个网站独占一个端口，
公网地址由隧道自动暴露，导航页统一展示。

---

## 一、端口段约定

预生成 `ports.txt`：`20001–20050`，共 50 个端口，按顺序使用。

| 端口 | 用途 |
| --- | --- |
| 80 / 8088 | 面板默认站点（导航页所在） |
| 20001–20050 | 你的各个网站，一个站一个端口 |

站点域名命名：`名字.后缀:端口`，例如 `test.com:20001`、`blog.example.com:20002`。

## 二、建站流程（面板操作，约 1 分钟）

1. 打开宝塔面板 → **网站** → **添加站点**
2. 域名填 `你的名字:端口`（如 `test.com:20001`）
3. 选 PHP 版本（若已装）或纯静态
4. 确定

然后什么都不用做 —— `sites-monitor.sh` 会在 20 秒内：
- 检测到新端口站点
- 自动起一条 `cloudflared tunnel --url http://127.0.0.1:<端口>` 隧道
- 把 `端口 -> 公网地址` 写进 `sites.txt`
- 重新生成导航页

**约 30 秒后刷新导航页**，即可看到新站公网地址，手机直接可访问。

## 三、导航页（我的服务器站点导航）

自动生成在默认站点根目录 `index.html`，包含：
- **宝塔面板**公网入口（一键进入面板）
- **站点列表**：每个站点的端口 + 公网地址（可点击直达）
- **建站方法**说明
- **可用端口**列表

刷新即可看到最新状态；删除站点后导航页自动同步（关隧道、清记录）。

## 四、常用操作

```bash
# 查看站点映射
cat sites.txt

# 手动为某个端口起隧道
PORT=20005 bash scripts/tunnel.sh site-20005 http

# 停掉某个站点的隧道（站点已删时监控会自动做）
pkill -f "cloudflared.*127\.0\.0\.1:20005"

# 端口用完了，扩展
seq 20031 20040 | sudo tee -a ports.txt
```

## 五、站点文件落盘位置

每个站点的文件在 `/www/wwwroot/<站点名>/`，全部位于持久目录（`persist-www.sh` 生效时），
沙箱重置不丢。

## 六、注意事项

- 面板里"添加站点"时**必须带端口**，否则会落到 80 端口被监控跳过（监控只扫非 80/8088 端口）。
- 同一个端口只能给一个站点用，端口冲突面板会报错。
- trycloudflare 临时隧道地址会变，导航页会在重启后由 `restore.sh` 自动刷新。
